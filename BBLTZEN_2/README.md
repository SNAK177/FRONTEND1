# Bubble Zen - Web App Bubble Tea

## Descrizione
**Bubble Zen** è un progetto web completo per un negozio di Bubble Tea.  
Include:
- Area cliente con menu, personalizzazione, dolci e carrello.
- Area admin con login, gestione prodotti, dashboard e statistiche.
- Design moderno, responsive e animazioni carine (bolle animate, hover effects).
- Struttura modulare di file HTML, CSS e JS.

## ⚡ Funzionalità principali

### Area Cliente
- **Home page** con animazioni di bolle e QR code.
- **Menu** con prodotti mostrati in card animate.
- **Personalizza** per creare il proprio Bubble Tea con topping e sciroppi.
- **Dolci** con elenco dei dolci disponibili.
- **Carrello** con riepilogo prodotti e totale.

### Area Admin
- **Login Admin** protetto (username/password).
- **Dashboard** con statistiche rapide.
- **Gestione Prodotti** (aggiungi/modifica/elimina).
- **Statistiche Vendite** con grafici interattivi (Chart.js).

---

## 🎨 Tecnologie utilizzate
- **HTML5 & CSS3** con layout moderno e responsive.
- **JavaScript** per interattività, animazioni e bolle animate.
- **Chart.js** per grafici delle statistiche.
- **SVG & immagini** per prodotti, icone e bolle animate.

---

## 🚀 Setup

1. **Clona o copia la cartella** `bblzen2` sul tuo computer.
2. Apri i file `.html` in un browser moderno.
3. Per la parte admin, apri `admin/login.html`.
4. Tutti i CSS e JS sono locali, quindi non serve server esterno per testare (puoi usare live-server per comodità).

---

## 🌐 Note
- Il progetto è **statico**, non include backend reale.
- Per rendere il carrello e login funzionanti realmente, occorre integrare un **backend** (Node.js, PHP, .NET, ecc.).
- Tutti i file sono modulari e facilmente modificabili.
